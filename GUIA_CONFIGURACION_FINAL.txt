COBERTURA ECT 2026 - CONFIGURACIÓN FINAL (SIN BLAZE PARA DRIVE)
===============================================================

Esta versión usa:
- GitHub Pages: alojamiento.
- Firebase Authentication: login del Staff.
- Cloud Firestore: Staff, cursos, roles y estados.
- Firebase Cloud Messaging: permisos/tokens de notificación.
- Google Apps Script + Drive: fotos y videos sin Cloud Functions.

1. FIREBASE
-----------
La configuración pública está en config.js.
Authentication Email/Password y Firestore deben seguir habilitados.
Publicá firestore.rules.txt si todavía no tenés las reglas de esta versión.

2. STAFF / ADMIN
----------------
- Sergio Quiroga: Administrador principal + Staff.
- Los administradores pueden dar/quitar rol admin a otros Staff.
- El Staff crea su acceso con código de invitación.
- Los no administradores no ven administración de Staff.

3. CURSOS
---------
Administradores pueden:
- asignar;
- asignarse;
- editar nombre, fecha, inicio, fin y aula/lugar.

4. CÁMARA + DRIVE
-----------------
Usá GUIA_CAMARA_DRIVE.txt.
No necesitás Blaze, Firebase Secrets, OAuth Playground ni Client Secret para Drive.

5. GITHUB PAGES
---------------
Subí los archivos a la raíz del repositorio.
Settings > Pages > Deploy from a branch > main > /(root)

6. NOTIFICACIONES
-----------------
Las notificaciones locales mientras la app está abierta funcionan en Spark.
Cada persona debe activar notificaciones en Cuenta.
La automatización con la app completamente cerrada mediante Cloud Functions NO forma parte del modo sin Blaze.

7. TUTORIALES
-------------
Polito guía el primer ingreso y el uso principal de la app.
Se puede omitir y volver a abrir desde Cuenta.

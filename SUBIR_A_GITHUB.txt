SUBIR ESTA VERSIÓN A GITHUB PAGES
=================================

Esta entrega está preparada especialmente para que NO tengas el problema anterior de las carpetas.

Al descomprimir el ZIP principal, todos los archivos que necesita GitHub Pages quedan en la RAÍZ.
No hay carpeta public/ ni data/.

1. Descomprimí el ZIP principal.
2. GitHub > tu repositorio > Add file > Upload files.
3. Seleccioná TODOS los archivos de la carpeta descomprimida.
4. Arrastralos a GitHub.
5. Commit changes.

Los archivos más importantes que tienen que verse directamente en la raíz del repositorio son:
- index.html
- app.js
- styles.css
- config.js
- data.js
- firebase-messaging-sw.js
- logo.png
- polito.png
- manifest.webmanifest

También podés subir como archivos normales:
- firestore.rules.txt
- firebase.json
- .firebaserc
- FUNCIONES_FIREBASE.zip
- las guías .txt

FUNCIONES_FIREBASE.zip NO se ejecuta en GitHub Pages y no molesta.
Solo se usa después, localmente, para desplegar los avisos automáticos con Firebase CLI.

GitHub Pages:
Settings > Pages > Deploy from a branch > main > /(root)

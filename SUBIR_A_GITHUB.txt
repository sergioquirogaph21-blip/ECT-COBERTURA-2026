SUBIR ESTA VERSIÓN A GITHUB PAGES
=================================

Esta entrega está preparada con todos los archivos web en la RAÍZ.
No hay carpeta public/ ni data/.

1. Descomprimí el ZIP.
2. GitHub > tu repositorio > Add file > Upload files.
3. Seleccioná todos los archivos de la carpeta descomprimida.
4. Arrastralos a GitHub.
5. Commit changes.

Archivos principales:
- index.html
- app.js
- styles.css
- config.js
- data.js
- firebase-messaging-sw.js
- logo.png
- polito.png
- manifest.webmanifest
- firestore.rules.txt
- GOOGLE_APPS_SCRIPT_Code.gs
- GUIA_CAMARA_DRIVE.txt

GITHUB PAGES
------------
Settings > Pages > Deploy from a branch > main > /(root)

GOOGLE DRIVE SIN BLAZE
----------------------
Esta versión NO usa Cloud Functions para Drive.
Primero desplegá GOOGLE_APPS_SCRIPT_Code.gs como Web App siguiendo GUIA_CAMARA_DRIVE.txt.
Luego pegá la URL /exec en config.js:

appsScriptUrl: "https://script.google.com/macros/s/.../exec"

Después subí config.js actualizado a GitHub.

La URL de Apps Script no es secreta.
No subas Client Secret, Refresh Token, Service Account JSON ni credenciales privadas a GitHub.
